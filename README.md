## Currently Building

### Arka

**Terminal-native AI agent with multi-provider LLM failover.**

Arka routes plain-English requests to local skills and tools while keeping the architecture provider-agnostic.

* **24** LLM providers
* **70+** built-in skills
* **75** MCP tools
* **320+** tests
* Local-first workflow
* Multi-provider failover
* CLI-native interface
* MCP support
* Automation-ready

```bash
pipx install "arka-agent[chat]"
```
